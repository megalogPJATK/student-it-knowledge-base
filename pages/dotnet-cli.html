Podstawowe polecenia Dotnet
PolecenieZnaczenie
dotnet new consoleTworzy projekt aplikacji konsolowej
dotnet new console -n NameOfTheProgramNadaje projektowi nazwę
dotnet runKompiluje i uruchamia program

dotnet -h lub dotnet --helpPokazuje instrukcje do używania podanej komandy
dotnet --infoPodaje informacje na temat instalacji .NET oraz środowisko komputera

dotnet tool searchWyszukuje w NuGet.org narzędzi z wyszukiwaną frazą
dotnet tool uninstallOdinstalowuje narzędzie z twojego sprzętu
dotnet tool updateUpdateuje narzędzie które jest zainstalowane na sprzęcie
