Ściąga Git i Github

Ściągi z przedmiotów informatycznych.

Podstawowe polecenia Git
PolecenieGdzie jesteś?Co robi/oczekiwany wynikJak sprawdzić?
git clone URLKatalog nadrzędnyPobiera repo i tworzy jego katalog.Wejdź do katalogu, uruchom git status.
git switch mainDowolny czysty branchPrzełącza na main.
git pull --ff-only origin mainmainPobiera aktualny main bez automatycznego merge commita.git status pokazuje zgodność z origin/main.
git switch -c feature/nazwaAktualny mainTworzy branch i od razu na niego przełącza.git branch oznacza nową nazwę gwiazdką.
git statusDowolny branchPokazuje branch oraz pliki zmienione i przygotowane.Sam wynik jest weryfikacją.
git add .Branch roboczyPrzygotowuje wszystkie zmiany w bieżącym katalogu.git status pokazuje „changes to be committed”.
git commit -m "docs: ..."Branch roboczyTworzy lokalny zapis przygotowanych zmian.git log --oneline -3.
git push -u origin feature/nazwaNowy branch roboczyPublikuje branch i ustawia śledzenie.Branch jest widoczny na GitHubie.
git pushOpublikowany branchWysyła kolejne commity, aktualizując otwarty PR.Commit pojawia się w karcie Commits PR-u.
git fetch originBranch roboczyPobiera informacje o zdalnych zmianach bez modyfikowania plików.git log --oneline origin/main -3.
git merge origin/mainBranch roboczy PR-uWłącza aktualny zdalny main; może ujawnić konflikt.git status i git log --oneline.
